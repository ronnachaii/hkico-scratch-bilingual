# HKICO Scratch Practice (TH/EN)

แบบฝึก Scratch (Primary 2-4) 9 ชุด (Set 1-9) ชุดละ 20 ข้อ แสดงผลสองภาษา ไทย/อังกฤษ สลับได้ด้วยปุ่ม TH/EN มีหน้าสรุปคะแนน (ข้อที่ถูก/ผิด ทบทวนเฉพาะข้อที่ผิด ทำชุดใหม่)

- เปิดหน้าเว็บ: `index.html` (บน GitHub Pages) หรือดับเบิลคลิก `เปิดหน้าเว็บ.bat` เมื่อใช้ในเครื่อง
- ห้ามเปิดไฟล์ `.html` โดยตรงแบบ `file://` เพราะบล็อก Scratch จะไม่แสดง ต้องผ่านเว็บเซิร์ฟเวอร์
- ไลบรารีใน `assets/vendor`: scratch-blocks 2.1.32 และ Blockly 13.3.0
